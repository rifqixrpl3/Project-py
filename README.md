# Project To Do List Python

## Deskripsi
Project ini adalah aplikasi To Do List sederhana berbasis CLI (Command Line Interface) menggunakan bahasa Python.

## Fitur
- Tambah tugas
- Lihat tugas
- Tandai tugas selesai
- Hapus tugas
- Keluar program

## Teknologi
- Python

## Cara Menjalankan
Jalankan program menggunakan perintah:

```bash
python main.py
